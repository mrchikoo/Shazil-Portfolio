Oct 2026 · Systems / Reverse engineering

iPhone OS 1.0, back online iPhone 2G emulation with Wi-Fi

Getting a 2007 iPhone emulator onto today's internet.

  • emulation
  • reverse engineering
  • python
  • webassembly
  • wat
  • javascript
  • networking
  • sdio
  • tcp/ip

I patched the WebAssembly emulator core: a Python patcher plus hand-written WAT modules add an SDIO window, a Marvell 88W8686 Wi-Fi card model and packet rings to emu.wasm. A separate patch delivers IRQ 42 (VIC1 bit 10), and a device-tree patcher sets the MAC address and reset GPIO. The build uses wabt.

Around that I wrote a Python relay for DHCP, DNS, ARP and TCP/UDP NAT. A host proxy reduces modern HTTPS pages to plain HTML and small JPEGs. A JavaScript keyboard bridge turns Mac keystrokes into on-screen taps. Reverse-engineering helpers (a device-tree dumper, kernel disassembly scripts, a headless trace harness) and docs, including an SDIO register map derived from the guest kernel, round it out.

OutcomeDriver attaches, firmware loads, Wi-Fi joins, HTTP browsing works. 22 relay tests pass.
CreditBuilds on Kelindi's 2007.mobile WebAssembly emulator. The emulator core, phone UI and firmware loader are theirs, and this repo redistributes none of it: the build downloads it and patches the WebAssembly. The Wi-Fi patches, browser proxy and keyboard bridge are mine.

Limits · The proxy has no JavaScript, CSS or logins. Keyboard typing is verified only in Safari's URL and search fields.

I fine-tuned a COCO-pretrained SSD MobileNet V2 FPNLite 320x320 with the TensorFlow Object Detection API on a custom dataset of four hand-gesture classes: ThumbsUp, ThumbsDown, ThankYou and LiveLong.
