Oct 2026 · Systems / Reverse engineering

iPhone OS 1.0, back online

iPhone 2G emulation with Wi-Fi

Getting a 2007 iPhone emulator onto today's internet.

I patched the WebAssembly emulator core: patch.py plus hand-written WAT modules add an SDIO window, a Marvell 88W8686 Wi-Fi card model and packet rings to emu.wasm. A separate patch delivers IRQ 42 (VIC1 bit 10), and a device-tree patcher sets the MAC address and reset GPIO. The build uses wabt.

I also wrote a Python relay for DHCP, DNS, ARP and TCP/UDP NAT. A host proxy reduces modern HTTPS pages to plain HTML and small JPEGs. A JavaScript keyboard bridge turns Mac keystrokes into on-screen taps. Reverse-engineering helpers (device-tree dumper, kernel disassembly scripts, headless trace harness) and docs, including an SDIO register map derived from the guest kernel, round it out.

Outcome

Driver attaches, firmware loads, Wi-Fi joins, HTTP browsing works. 22 relay tests pass.

CreditBuilds on Kelindi's 2007.mobile WebAssembly emulator. The emulator core, phone UI and firmware loader are theirs, and this repo redistributes none of it: the build downloads it and patches the WebAssembly. The WebAssembly patches, Wi-Fi, browser proxy and keyboard bridge are mine.

Known limits: the proxy has no JavaScript, CSS or logins. Keyboard typing is verified only in Safari's URL and search fields.

Mar 2024 · Computer vision

Hand-gesture Object Detection

TensorFlow Object Detection API · computer vision

Fine-tuned SSD MobileNet to spot hand gestures live from a webcam.

I fine-tuned a COCO-pretrained SSD MobileNet V2 FPNLite 320x320 model with the TensorFlow Object Detection API on a custom dataset of 4 hand-gesture classes: ThumbsUp, ThumbsDown, ThankYou and LiveLong. I collected the images from a webcam with OpenCV, labelled them with labelImg and converted them to TFRecords.

Outcome

Trained for 3,500 steps (batch size 4) and exported as a TensorFlow saved model. Runs live webcam inference with OpenCV, and a small Flask app streams the webcam feed.
