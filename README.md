# Shazil Katchhi - Portfolio

Personal portfolio of **Shazil Katchhi**: M.Sc. Artificial Intelligence student at BTU Cottbus-Senftenberg, based in Berlin. Computer vision, edge ML and the data pipelines behind them.

A static site: plain HTML/CSS/JS, no build step, no dependencies beyond Google Fonts.

## Pages

| File | Description |
|---|---|
| [`index.html`](index.html) | Main portfolio, styled as a small handheld device ("SK-01"): about, experience, projects, toolkit, words, contact, CV. Keyboard navigation (arrows, `N` night mode, `M` mail, `G` GitHub, `L` LinkedIn, `?` keys). |
| [`vision.html`](vision.html) | Alternate, clean scrolling layout of the same content. |
| [`archive/`](archive/index.html) | Earlier designs kept for reference (editorial, N64, macOS, PS5, Switch, XMB). |
| [`assets/profile.jpg`](assets/profile.jpg) | Profile photo. |
| [`Shazil_Katchhi_CV.pdf`](Shazil_Katchhi_CV.pdf) | CV. |

## Run locally

```bash
git clone https://github.com/mrchikoo/Shazil-Portfolio.git
cd Shazil-Portfolio
python3 -m http.server 8000
# open http://localhost:8000
```

Opening `index.html` directly in a browser also works.

## Deploy

Any static host works. On GitHub Pages: Settings > Pages > deploy from the `main` branch, root folder.
